# AMR 阶段 1：逐层时间外推实施记录

本次在 `7b575c0e2` 上实现公共时间历史和泊松初值接入。功能代码已写入，
当前会话无 CLion 工具，尚未编译或运行 WarpX，数值验收保持未完成。
本阶段只处理从头启动的连续模拟，不实现 restart。

## 公共组件与接入范围

- `ablastr::fields::NodalPoissonInitialGuess` 统一管理历史和节点未知量掩码。
  每层独立保存最多三份有效区电势、时间戳和历史深度，历史场与求解场不共享存储。
  历史不保存 ghost；存储及分配、提交辅助函数保持私有，降阶与有限性回退在
  公开的 `prepare()` 中执行，以满足 CUDA 对 extended device lambda 所在函数的访问要求。
  不再保留独立历史类及其编译单元。不依赖 Insert、材料系数、粒子或碰撞对象。
  以 `MLNodeLinOp::buildMasks` 相同的 cell coverage 规则识别局部细区接口，
  再排除物理 Dirichlet 及调用方提供的固定电势掩码；不使用粒子 buffer masks。
- 上层持有该组件，通过 `PoissonLevelPrepare` 回调在每层求解前直接准备 `phi[lev]`。
  通用 `computePhi` 不接收具体历史控制器，也不另设初猜场或粗插值工作场。
- Cartesian 2D/3D、非 EB 的 lab-frame MLMG 接入新组件。材料路径借用相同公共组件；
  单层 Robin 的物理面仍为未知节点，内部阳极仍排除在预测之外。
  Robin 算子自身的单层限制未放开。
- EB、RZ、1D 直接求解、FFT/IGF 和 Python Poisson callback 保留原有历史/初值路径，
  不在本阶段扩展它们的 AMR 外推能力。旧私有辅助函数仅用于这些兼容路径，
  新 Cartesian nodal MLMG 路径不分配旧历史场。

## 求解顺序与不变量

1. 当前物理边界与材料约束完成初始准备，配置各层掩码及历史布局。
2. level 0 只在有效未知节点写入历史初值，随后按既有路径求解。
3. 粗层求解后，仍调用原 `interpolatePhiBetweenLevels`，使用相同系数、细化率、
   通信精度与 ghost 宽度，仍直接写入下一层 `phi`。
4. 轮到细层求解时，回调只对有效未知节点预测，无历史时保留粗插值初值。
   物理 Dirichlet、粗细接口、阳极和所有
   ghost 均不参与预测，包括 order 0 和非有限回退；同层 Box 接缝的未知节点正常参与。
   原生及材料后端继续负责既有约束恢复，并从同一个 phi 场读取初猜及写回解。
5. 各层求解完成后沿用既有 phi ghost 处理，再一次性提交各层历史。computeE、
   aux/cax、粒子 gather/deposition、SyncRho 和缓冲区分区未修改。

首次 level 0 沿用合法现有初值，首次细层内部用粗插值；历史不足按层降阶。
相同求解时间只替换最近样本，不推进历史。场时间间隔变化时保留最近解并降至 order 0，
随后按新间隔重新积累历史；高阶预测出现非有限值时整层退回最近有限解，固定区域不变。
纯周期/Neumann 的无固定节点问题在历史副本中使用节点体积权重和唯一所有权归一化
电势零点，不修改求解后的物理 phi 或其电场。

布局、Geometry、边界类型或固定掩码对象变更会使相应层的掩码/历史失效；
固定材料和掩码内容仍遵守静态约定。本阶段不实现动态 regrid 或可变材料。
候选选择目前提供降阶和有限性回退；没有引入额外物理残差求解或候选性能优劣判据。
verbosity >= 2 输出每层实际 history_order、时间间隔变化和有限性回退状态；
history_order=-1 表示使用无历史初值。
