# AMR 阶段 2：独立耦合 MCC 实施记录

本次在 `fe599f11c` 上完成阶段 2 的源码实现。当前无 CLion 工具，尚未完成编译或运行
验收；按用户要求，不创建测试输入文件、Python 脚本或 CTest 注册。

## 支持范围与模块边界

- 3D 静态 AMR 的直接中性背景密度模式可独立于材料和电势外推启用。
  仅配置普通原生碰撞时，不初始化耦合背景数据。
- 多层模式在 MCC 入口拒绝非 3D、AVERAGE_USE/CALC、IONIZATION_SOURCE_RECORD/INJECT、
  MCC_ION_CACHED_RHO 和 MCC_EXCITATION。背景初始化拒绝 regrid、负载均衡、moving window
  和 AMR 时间 subcycling；布局变化也有运行时检查。原有 ECDI 多层限制保留。
- 中性密度和消耗场使用层级布局独立分配，不访问泊松 rho_fp/rho_cp/rho_buf。
  中性密度沉积仍使用既有 DepositCharge 接口写入私有场，沿用现有输入中中性物种
  `charge=1` 的数密度约定；未改变物种电荷、权重、截面、SEE 或注入参数。

## 层级数据与粒子生命周期

1. 每次实际直接 MCC 调用前重建背景密度、bins 和可消耗数量。这覆盖第一次碰撞、
   中性物种 `ndt=1`、排序、跨层/跨 rank 迁移、注入、墙面产物及碰撞子步。
   CALC 模式保留其单层采样入口，USE 模式仍从文件初始化。
2. bins 按 `(lev, box, tile)` 管理，遍历所有本地 tile，包括空 tile；
   不再假设一个 FAB 只有一个粒子 tile，也不依赖初始化时已有中性粒子。
3. 每层分别计算密度上界，包含取样可能访问的 ghost，并据传入的碰撞 dt 计算
   散射/电离概率。空背景和零碰撞率不会进入除以零的碰撞核。
4. 散射使用当前层坐标；电离密度取样使用 FAB 坐标，背景消耗索引使用 cell-centered
   tile 坐标。新电子与离子在当前层当前 tile 创建，空产物 tile 正确定义运行时属性。
5. 可消耗数量按有效中性宏粒子的完整电子权重单位累加，消耗后不保留负权重；
   不把多个不足一个单位的残余权重合并成无法从单个粒子兑现的请求。
6. 私有消耗场继续执行同层跨 Box/MPI 求和及既有物理边界处理，再从本层私有背景密度扣除。
   CPU 端按 tile 顺序执行电离，避免重叠节点沉积和空产物 tile 创建时的线程竞争；
   GPU 粒子核继续并行执行。

原生 CollisionHandler 的 start_step、subcycle/supercycle、传入时间及 dt 不变。
species `ndt` 仍控制原有推进节奏，不作为碰撞 bins 有效性的判断依据。
现有注入使用临时 level 0 写入及位置归属；原生边界处理后的完整 MR Redistribute
继续负责双向跨层迁移和墙面产物归属。没有增加碰撞专用的场同步或粒子电荷沉积。

## 保留的限制与验证状态

背景仍只由本层中性粒子沉积，不跨层限制或补齐粗细接口缺项。主要电离区应与接口
隔开；该近似的碰撞偏差仍需物理验收，不能由源码检查宣称满足误差预算。
每次碰撞重建背景与 bins 增加计算和同步开销；性能尚未测量。

已核对原生取场、aux/cax、gather/deposition、SyncRho、粒子分区、CollisionHandler、
注入和墙面主路径没有修改。源码检查不等于 MPI/GPU 编译或守恒验证通过。
原生无材料运行、外推组合、各层消耗/产物守恒及迁移后的运行观测仍待完成。
