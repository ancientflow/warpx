# 阶段 6：原生路径一致性与 AMR 自力验收

日期：2026-10-26 至 2026-10-27。
实施起点：`a3aeb647eaaf664560557083074a5e1adb1ab9c2`。
范围：3D Cartesian、静态内部细区、显式 lab-frame 静电、线性粒子形状。
本记录区分公共路径缺陷、不同离散算子的误差、以及有限缓冲宽度下的接口自力。

## 基线与数据路径

源码上游对照固定为 `29bf29d4f9181bcbf01a881f6a94e1c43e6e4884`
（`Add Darwin solver (#6293)`），AMReX 为
`b552c85c432defab450688581a1c87aead7b461d`。
数值原生对照使用本分支关闭材料的程序，包含阶段 5 公共 cax 刷新修复；
没有将它表述为完全干净的官方 checkout 的运行结果。

| 路径 | 核查结果 |
|---|---|
| 粒子分区 | `Partition.cpp` 与上述上游提交逐字一致；按原有 masks 重排，保持 `lev/lev-1` 选择 |
| 电荷沉积 | `ChargeDeposition.H` 与上游逐字一致；静电主入口按粒子所属层沉积，传空 `rho_buf` 给 SyncRho |
| SyncRho | 函数体与上游逐字一致；从细到粗限制、ParallelAdd、OwnerMask 去重，再作同层求和 |
| computeE | 3D 差分不变；整个文件的已有差异包含选项/回调重构和其他维度修正，不能声称整个文件一致 |
| gather | 显式 `doGatherShapeN` 不变；整个头文件另含上游隐式/RZ 修改 |
| phi ghost | 公共粗插值先填细层及 ghost；材料只刷新同层数据并处理物理外边界，不另造粗细插值 |
| E/aux/cax | 求解、computeE、外加网格场、FillBoundary、aux/cax 更新，然后取场；Evolve 的缓冲分区及取场内核不变 |
| 半步同步 | 本阶段发现并修复 PushP 未按缓冲区选择 cax 的问题，见下节 |

原生无 EB、beta=0 的算子为 `MLNodeTensorLaplacian` 的七点模板；
材料算子使用 AMReX `mlndlap_adotx_aa` 的变系数节点模板。
因此 `epsilon=1`、无电极时，两者的连续问题相同，但离散系统并不逐点相同。
点电荷附近高频场的差异不能当作求解残差或 MPI 错误；退化对照同时检查
相同源、光滑源的网格收敛以及粒子实际受力。

Full 诊断的 `RhoFunctor` 会重新按层沉积粒子，并非直接输出求解器 SyncRho 后的数组。
尤其粒子形状跨细区边缘时，直接积分 plotfile 的 rho 不能用作同步电荷守恒证明。
本阶段在 SyncRho 后对 level 0 节点进行唯一所有者求和并乘网格体积；
小问题没有物理边界上的粒子，不涉及外域半控制体积修正。

## 本次代码修复

1. 允许 level 0 的材料电极 mask 为空，用于纯介质或真空问题。
   `anode_implicit_function=1`、`anode_potential_function=0` 表示无内部电极；
   物理边界及局部细层覆盖约束仍存在。有电极时保留原有厚度检查。
2. `PhysicalParticleContainer::PushP` 现在使用原有
   `PartitionParticlesInBuffers`，分别在本层 aux 和上一层 cax 上推进动量。
   提取的 `PushMomentum` 仅更新指定粒子子集的动量，沿用原有 gather 和 pusher，
   同步移动位置/外场/动量/电离态数组的 offset，不调用含位置和 QED 时间演化副作用的 PushPX。
   该方法含 CUDA 扩展 device lambda，声明放在 public 区域。

修复前，正常一步推进读取 cax，而初始 `-dt/2` 和输出同步 `+dt/2` 均读取细层 aux。
在近似不动的粒子上，静态场的前后半步差可以抵消，因而阶段 5 的恒定场探针未暴露它。
当粗细两套场都随时间变化时，同步速度多出
`(q/m)*dt/2*((E_f(T)-E_c(T))-(E_f(0)-E_c(0)))`。
该预测与修复前 collocated、staggered-to-nodal 探针的实测动量差吻合至
`2.2e-8 m/s`；新一组避开网格面的探针中，接口粒子的时间响应误差最高为 6.40%。

通过 CLion debugger 尝试检查缓冲区分支时，原 Release 构建报告
“没有可执行代码与此行相关联”，未获得该构建的断点变量证据。
随后使用临时诊断记录实际 `np/nfine_gather`、半步 `gather_lev/offset`、
cax 的更新时间和分量范围、SyncRho 后电荷，并以解析时间响应交叉验证。
这些临时诊断不作为交付功能保留。

CPU RelWithDebInfo 构建随后取得真实断点证据：CLion session 78 在
`PushMomentum` 中读到 `lev=1`、`gather_lev=0`、`offset=1`、`np=1`、
`dt=-5.0000000000000002e-11`。调用栈为 PushMomentum → PushP 的 OpenMP
循环 → PhysicalParticleContainer::PushP → MultiParticleContainer::PushP → Evolve。
已移除本次断点，保留用户断点；会话正常退出。

## 小问题设置与验收预算

已有 `Examples/Tests/electrostatic_sphere/inputs_base_3d` 加命令行覆盖：
域 `[-0.5,0.5]^3`，粗层 `32^3`，细化比 2，细区 `[-0.25,0.25]^3`，
`n_error_buf=0`、max grid size 16、blocking factor 8。
Dirichlet 六面零电势；Robin 与其自身同边界均匀网格参考比较，不与 Dirichlet 解混用。
关闭滤波和碰撞，介电常数 1，无内部电极。各次命令记录在运行目录的 `command.json`。

- 单粒子力：电子宏粒子权重 `1e6`，初速度零，`dt=1e-12 s`、一步，
  由同步动量得到 `E_seen=-m_e*u/(e*dt)`。扫描面、棱、角及不同子网格位置，
  缓冲宽度 0/2/4/8；0 仅为误差对照。
- 穿越轨迹：初始位置 `(0.140625,0.0078125,0.01171875)` m，
  初始 `u_x=4e5 m/s`，`dt=1e-8 s`、40 步；另作反向穿越。
  比较所有输出时刻，不仅比较终点。参考为同域均匀 `64^3`。
- 时变场：`potential_hi_x=0.25+1e9*t`，其余五面为零；三个近乎无自场探针
  分别位于细区内部、缓冲带、粗区。对照固定面电势 0.25 的微小时间步结果，
  检验线性时间因子的积分；探针避开零阶 Galerkin 取场的网格分界面。

首批扫描用于定位误差和选择缓冲宽度；随后在独立位置和修复后的重复运行前固定
小问题预算（`build/amr-stage6-acceptance.json`）：受力相对同边界参考误差 10%，
材料/原生缓冲受力差 5%，轨迹最大偏移 0.01 个最细网格，动量误差/初始动量 0.001，
时间响应相对误差 `1e-6`，电荷相对误差 `1e-12`。
光滑源退化对照沿用 phi/E 相对 RMS 5%/10% 的空间预算。
这些是所述小问题的判据，不是生产工况或任意宏粒子权重的通用保证。

## 验证结果

### 构建与运行时一致性

全部编译通过 CLion 的 `app_3d`，没有命令行编译。

- GPU：原 Release 配置，CUDA 13.2、DOUBLE、MPI，EB/FFT/QED/openPMD 开启。
  新 helper 的 public 声明修复了 CUDA 对扩展 device lambda 的访问权限要求；
  完整目标构建通过，不能以早期单个对象编译成功代替链接成功。
- CPU：`build/stage6-cpu`，OMP/MPI、DOUBLE、RelWithDebInfo、`-O1 -g -DNDEBUG`，
  EB/FFT/QED/openPMD 关闭，运行使用 2 个 OpenMP 线程。
- 去掉临时诊断后，两种构建均重新通过；正式源码没有 STAGE6 日志或诊断开关。
- 两层时变场覆盖 collocated、staggered-to-nodal、staggered 能量守恒取场，
  原生与材料各三组；GPU 最大相对时间响应误差 `3.44e-10`，CPU 同样通过 `1e-6` 门槛。
  双 MPI rank 的材料探针与单 rank 动量一致。另验证 `gather_from_main_grid`，
  CPU 原生/材料误差分别为 `2.33e-10` / `1.92e-13` 以下。
- 三级时变场覆盖四个位置，三步/一步的动量时间比例误差低于 `3.30e-10`。
  单独的三级恒定边界重复求解参考曾因约 `1.36e-12` 的残差下限未达到
  `1e-12` 绝对容差而退出；保留失败记录，没有放宽容差将其记为通过。
- 非零磁场 `Bz=0.001 T`、初始 `u_x/c=1e-4` 的三个位置探针覆盖原生、
  Dirichlet、Robin 和两种场布局；GPU 相对回旋动量误差 `1.37e-12` 以下。
  另用原生 Yee 电磁模式检查恒定场推进，CPU 相对误差 `5.03e-14` 以下。
- 三级材料时变场的 CUDA memcheck 正常退出，`ERROR SUMMARY: 0 errors`。

临时运行诊断确认，三探针的细层 `np=2,nfine_gather=1`，另一个粒子在 level 0。
时变电势驱动下 cax 分量范围按当前时间更新；不是仅观察到缓冲区被分配。
SyncRho 后的 level 0 电荷与粒子总电荷比较，力扫描、独立位置、布局及
40 步轨迹合计 1503 个采样的最大相对误差 `3.16e-16`。

### 退化对照与布局

同一光滑高斯电荷源、同一外边界、epsilon=1、无内部电极。
采用复合体积权重，排除被细层覆盖的粗格和距物理边界两格的区域；
比较对应网格上的 rho、phi 和三分量 E，而非混用两种算子的离散残差。

| 粗层分辨率 | rho 相对 RMS 差 | phi 相对 RMS 差 | E 相对 RMS 差 |
|---|---|---|---|
| `32^3` | `0` | `1.966e-3` | `2.975e-3` |
| `64^3` | `3.76e-18` 以下 | `4.929e-4` | `7.537e-4` |

加密后差异约缩小四倍，符合两种离散格式趋向同一连续问题的预期。
另分别启用介电跳变和体电极，确认独立物理变化可求解；这些运行不替代阶段 3–5
的材料边界精度验收。max grid size 16/32、1/2 MPI ranks 的力对照通过；
将相对/绝对求解容差收紧到 `1e-12/1e-14` 后，受力相对变化最大约 `1.04e-7`，
远小于下面的空间误差。

### 接口力：保留失败配置

第一组 11 个位置覆盖细区面、棱、角、不同子网格位置及粗区。
下表是相对同边界均匀细网格的最大向量场差，单位 V/m；使用原始 `32^3` 粗层。

| 缓冲宽度（细格） | 原生 Dirichlet | 材料 Dirichlet | 材料 Robin |
|---|---|---|---|
| 0 | `6.088e-1` | `7.673e-1` | `7.673e-1` |
| 2 | `2.989e-2` | `4.645e-2` | `4.648e-2` |
| 4 | `1.362e-3` | `3.164e-3` | `3.180e-3` |
| 8 | `4.566e-5` | `1.574e-5` | `1.003e-5` |

这组位置中的 8 格结果不能推广到整个过渡区。独立位置检查发现 8 格缓冲刚外侧的
受力相对误差仍可达原生 10.3%、材料 Dirichlet 20.9%、Robin 51.9%。
随后分别扫描过渡区两侧的四分之一格相位与三个横向相位：

| 配置 | 原生最坏受力误差 | 材料 Dirichlet | Robin | 判定 |
|---|---|---|---|---|
| 粗层 `32^3`、12 格缓冲，27 个位置 | 5.85% | 10.26% | 23.80% | 材料组合未全部通过 |
| 粗层 `64^3`、16 格缓冲，27 个位置 | 3.59% | 6.48% | 16.15% | Robin 未通过 |
| 粗层 `64^3`、24 格缓冲，21 个位置 | 1.48% | 2.65% | 6.20% | 三者均通过 |

最后一组的材料/原生 Dirichlet 受力相对差最大为 1.15%，通过 5% 门槛。
GPU 对照包含最坏位置和过渡区两侧的位置。24 格配置的运行诊断还确认：
距 patch 边缘 22.25 格的粒子 `nfine_gather=0`，24.25 格的粒子
`nfine_gather=1`，没有通过把所有细层粒子改成粗层取场来取得结果。

24 格是该域、网格、粒子形状及预算下的实测配置，**没有改写程序的默认缓冲宽度**。
该小 patch 的有效细层取场区域因此缩小；生产配置应联合选择 patch 大小、粗层分辨率
及缓冲宽度，不能只复制这个数字。

### 完整穿越与交错网格限制

最终穿越配置为粗层 `64^3`、24 格缓冲，参考为均匀 `128^3`。
正向从 `(0.02734375,0.0078125,0.01171875)` m 出发，反向从
`(0.26734375,0.0078125,0.01171875)` m 出发，`u_x=±4e5 m/s`，
`dt=1e-8 s`，60 步，保持权重 `1e6`；起终点分别在有效细区内部和粗区。

正向原生运行的实际分区为：步骤 0–8 在 level 1 取细场，9–55 在 level 1
读取 level 0 cax，56–59 已迁移到 level 0。初始/诊断半步采用相同场来源。
这同时覆盖取场过渡和粒子 Redistribute 的层间迁移。

| 后端 | 两方向最大位置误差 / 最细格 | 最大动量误差 / 初始动量 |
|---|---|---|
| 原生 Dirichlet | `1.077e-5` | `5.690e-7` |
| 材料 Dirichlet | `7.262e-6` | `2.640e-7` |
| 材料 Robin | `1.002e-5` | `5.423e-7` |

均通过 `0.01` 格和 `0.001` 的预算。CPU/GPU 正向原生轨迹差小于
`3.56e-15` 个细格、`2.94e-16` 倍初始动量。

交错网格采用原有 energy-conserving/Galerkin 取场时，`32^3` 粗层、8 格缓冲、
权重 `1e6` 的 40 步问题**未通过**：最大轨迹差约为原生 0.811 格、材料两种边界
0.936 格，最大相对动量差可达 0.187。这个向外运动的 8 格配置初始即位于取场缓冲区；
均匀粗/细网格对照的终点位置差同样为 0.811 / 0.935 / 0.936 格，说明不能把这项
网格依赖全部归因于粗细接口，也不能当作材料专有的取场错误。
原有 AMR 理论文档区分了动量守恒取场的逐点自力消除和能量守恒取场的格内平均性质；
不能用 collocated 的通过结果替代交错取场的单粒子验收。

同一 40 步问题另以权重 1 和 `1e3` 检查：CPU 上三种边界/后端均通过轨迹预算，
其中 `1e3` 也通过 GPU 对照，最大位置/动量误差分别为 `0.004918` 格和 `9.481e-4`。
这是指定参数下的实测结果，不是任意算例的粒子权重上限。
未改变 gather 阶数或引入 FAC/双向场耦合来掩盖未通过的配置。

## 记录与范围

命令行、完整日志和 plotfile 位于 `build/amr-stage6-*/`；每个新运行的
`command.json` 记录实际 argv，`result.json` 记录退出状态。
主要前缀：`cpu-` 为带临时诊断的完整扫描，`cpu-clean-` 为清理后的补充扫描，
`gpu-` 为最终 GPU 对照，`trace-` 为固定诊断二进制的分区证据。
`amr-stage6-*-summary.json` 保存分析结果，`amr-stage6-provenance.json` 保存版本，
`amr-stage6-debugger-evidence.json` 保存断点读值，
`amr-stage6-instrumentation.patch` 保存临时诊断差异。

复现使用这些记录中的 argv 和已有球形输入，工作目录为对应 command.json 所在目录；
分析在终端内联执行，没有新增测试输入、
分析脚本、CTest 注册或 checksum 文件。调试使用 CPU 自身的 used-inputs；
GPU used-inputs 中的 profiler 同步设置不能原样作为 CPU 调试配置。
